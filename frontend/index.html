Architecture Overview & "Whiteboard Defense" Benchmark

Engineering Depth

1. Event-Driven Ingestion Architecture

Why NOT a direct API Gateway endpoint? Standard API Gateway integrations enforce a strict 10MB payload cap and a 29-second execution timeout. If thousands of rows are uploaded synchronously, cold starts, parsing spikes, and network drops cause request failures and high memory costs.

The Solution: Direct-to-S3 Pre-signed PUT URL. The client uploads the raw CSV directly to Amazon S3. S3 emits an asynchronous ObjectCreated event notification to an ingest Lambda worker. The worker streams the file using memory-bounded chunking (500 records per batch insert), executing bulk upserts with ON CONFLICT (user_id) DO UPDATE.

2. The Optimization Treasure Hunt (3-Stage Sifting Funnel)

The Problem: Evaluating 10,000 borrowers against 15 loan products yields 150,000 candidate pairs. Evaluating every single pair with an LLM would require 150,000 API requests, costing hundreds of dollars and taking over 40 hours of latency!

Stage 1

Indexed SQL Relational Filter

B-Tree indexed filters (income >= min_income, credit_score >= min_credit_score, age BETWEEN min_age AND max_age, employment_status match). Eliminates 95% of invalid pairs in milliseconds at zero cost.

Stage 2

Algorithmic Scoring & Top-K Sifter

Calculates a weighted composite score (Credit Headroom 35%, Income Coverage 30%, Rate Appeal 20%, Employment Stability 15%). Sorts and caps candidates to at most Top 3 loan products per user.

Stage 3

Batched Qualitative LLM Advisory

The LLM is invoked only once per matched borrower for their top shortlisted offers in a structured JSON batch. It synthesizes qualitative credit underwriting guidance and rate negotiation tips.

3. Safe Notification Workflow (AWS SES Sandbox)

Security & Anti-Spam Guardrails: The system enforces safe test inbox routing. It never attempts to send emails to the dummy @example.com addresses in the dataset. Instead, it reroutes notifications strictly to the evaluator's verified test aliases (e.g. abcd+test@gmail.com), while storing rendered HTML artifacts for instant local review.
